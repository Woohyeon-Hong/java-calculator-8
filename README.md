# java-calculator-precourse

## **🎯 기능 목록**

### 입력값 처리
- [x]  **계산기 시작 문구**를 출력한다.
- [x]  **문자열**을 입력받는다.
- [x]  **커스텀 구분자**를 처리한다.
    - [x]  **커스텀 구분자** 있는지를 판단한다.
        - [x]  `//`로 시작하는지 확인한다.
    - [x]  **커스텀 구분자**가 있으면, **구분자 목록**에 추가한다.
        - [x]  커스텀 구분자 등록 예외를 처리한다.
            - [x]  `예외 처리` : **커스텀 구분자**로 **문자열**이 입력된 경우
            - [x]  `예외 처리` : **커스텀 구분자**로 **숫자**가 입력된 경우
        - [x]  **커스텀 구분자** 개수를 확인한다.
        - [x]  모든 **커스텀 구분자**들을 구분자 목록에 추가한다.
- [x] 숫자 추출 시 발생 가능한 예외 처리를 한다.
    - [x] `예외 처리` : 구분자가 아닌 문자가 입력된 경우
    - [x]  `예외 처리` : `0`이나 `음수`가 입력된 경우
- [x]  `문자열`에서 **숫자**들을 추출한다.

### 연산 수행
- [x]  추출된 숫자들을 모두 더한다.

### 결과 출력
- [x] 연산 결과를 출력한다.
  - [x] 연산 결과가 정수 값일 경우, 소수점 이하를 제거하고 출력한다.
  - [x] 연산 결과가 실수 값일 경우, 소수점 첫 번째 자리까지 출력한다.
