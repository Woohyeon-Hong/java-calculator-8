# java-calculator-precourse

## **🎯 기능 목록**

### **입력값** 처리

- [ ]  **계산기 시작 문구**를 출력한다.
- [ ]  **문자열**을 입력받는다.
    - [ ]  `예외 처리` : `,` , `:` , `//커스텀_구분자\n`  , `양수`가 아닌 값이 입력된 경우
    - [ ]  `예외 처리` : **커스텀 구분자**로 **문자열**이 입력된 경우
    - [ ]  `예외 처리` : **커스텀 구분자**로 **정수**가 입력된 경우
- [ ]  **커스텀 구분자**를 처리한다.
    - [ ]  **커스텀 구분자** 있는지를 판단한다.
        - [ ]  `//`로 시작하는지 확인한다.
    - [ ]  **커스텀 구분자**가 있으면, **구분자 목록**에 추가한다.
        - [ ]  **커스텀 구분자** 개수를 확인한다.
        - [ ]  모든 **커스텀 구분자**들을 구분자 목록에 추가한다.
- [ ]  `문자열`에서 **숫자**들을 추출한다.

### 연산 수행

- [ ]  추출된 숫자들을 모두 더한다.

### 결과 출력

- [ ]  연산 결과를 출력한다.
